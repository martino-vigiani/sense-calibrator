PS5 controller stick drift test

The PS5 controller stick drift test reads the resting signal of both sticks and tells you whether either one sits off center or wanders while untouched. It is read-only: no calibration or memory command is sent.

Open Sense Calibrator Desktop Chrome or Edge · USB data cable · standard DualSense

What stick drift is

Stick drift is what happens when a stick reports a non-zero signal while nothing is touching it. The controller keeps sending values that are not neutral, and the game reads phantom movement: the camera creeps, the character walks slowly, a menu selection slides on its own.

Two shapes matter when you test:

  • A stable offset. The resting position is consistently wrong. Samples settle around the same non-neutral coordinates, and the same offset reappears from one test to the next.
  • An unstable or noisy signal. The value wanders even while the stick is at rest, so no single resting position explains it.

The two can feel similar in a game, but they point to different causes. That is why the test reports an offset figure and a noise figure separately instead of a single pass or fail.

What you need

  • A desktop computer. Windows, macOS, Linux or ChromeOS. Phones are not supported.
  • The standard PS5 DualSense. Only the standard controller is supported.
  • A USB data cable. Some cables only carry power. If the controller never appears in the browser prompt, try another cable before anything else.
  • Desktop Chrome or Edge. The browser talks to the controller through WebHID, which Chromium browsers provide and Safari and Firefox do not.

The calibration side of the tool rejects Bluetooth, so USB is required for the full workflow. If the controller is paired wirelessly, plug it in with the cable and connect again.

How to connect

  1. Plug the DualSense into the computer with the USB data cable.
  2. Open Sense Calibrator in Chrome or Edge.
  3. Select Connect DualSense.
  4. Approve the browser prompt and pick the controller from the list.
  5. Confirm that the status chip shows the controller as connected.
  6. Put the controller on a stable surface, away from anything that can tap or vibrate it.

How the automatic test measures drift

The run is automatic. After a short settling period, the test samples the stick's input reports for about three seconds, at roughly the rate the controller sends them.

Only steady samples count. For each sample, the tool checks how far the signal moved across a short window of recent reports. A sample with a small spread is kept; a sample that moved is discarded as movement, because a hand brushing the stick, a cable tug or a vibrating table is movement, not drift. If too few steady samples remain, the test discards the attempt and starts over.

From the samples that remain, it reports two numbers per stick:

  • Resting offset: the median stick position, as a percentage of the full range.
  • Noise: how far individual samples scatter around that median.

Stability classification is what keeps the result honest, because the test cannot see your hand. It can only see the signal, and a value that is merely moving is not drift. The measurement logic is open source and documented: read the implementation in the GitHub repository and the protocol notes in the SubraLabs technical write-up.

How to read the result

Each stick gets a label from its offset: Centered under about 1.2% of range, Mild drift up to about 3.5%, and Marked drift above that. Noise is judged separately, and anything above about 1.5% is flagged as a sign of a worn or dirty signal.

Reading What the numbers show What it points to
Centered Offset under about 1.2%, with low noise and a thin, steady cloud of samples. A quiet resting signal. There is nothing to correct.
Stable offset Offset above the centered band, but the same position repeats closely on a second test. A stored calibration offset, which calibration may correct.
Noisy signal Noise above about 1.5%; the position wanders around the median instead of settling. The sensor itself, often wear or dirt. Software is unlikely to help.

Read both numbers together, not just the offset. A large offset with a quiet signal is a better candidate for calibration than a small offset that will not hold still. Re-run the test before acting on it: one noisy run on a wobbling surface can look worse than the stick really is.

Why the test is read-only

The PS5 controller stick drift test only reads input reports. It sends no calibration command and no memory command, so nothing on the controller changes while it runs. There is also nothing to save or undo afterwards.

Read-only by design. Calibration is a separate, explicit step that you choose later, and it stays temporary until you write it to the controller's memory.

Why a test cannot diagnose every mechanical problem

The test measures the electrical signal at rest. It does not inspect the mechanism, so several faults stay invisible to it:

  • Worn or dirty potentiometer tracks
  • Dirt or debris inside the module
  • A cracked housing
  • A bent shaft
  • Intermittent faults that only appear under heat, pressure or rumble

A quiet signal at rest is a good sign, but it is not proof that the stick module is healthy. If a stick misbehaves in a game while the test reads clean, the conditions that trigger the fault may simply not be present at rest.

What to do after the result

  • Centered and quiet: there is nothing to fix. Test again later if something starts to feel off.
  • A stable offset: the guide on how to calibrate a DualSense controller explains whether calibration fits and how to keep the result saved.
  • A noisy signal: calibration is unlikely to help. Cleaning, repair or module replacement may be the realistic path.

Whatever the result, run the test a second time to confirm it, and compare the numbers again after any change you make.

Run the PS5 controller stick drift test

Connect the controller over USB on a desktop in Chrome or Edge, leave both sticks alone, and read the resting offset and noise in a few seconds.
