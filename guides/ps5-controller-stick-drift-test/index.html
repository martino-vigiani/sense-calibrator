PS5 controller stick drift test

To test PS5 stick drift, connect a standard DualSense by USB in desktop Chrome or Edge, release both sticks and open Sense Calibrator. The automatic test measures resting offset and signal noise without calibrating or writing to memory.

What stick drift is

Stick drift is unwanted input when you have released the stick. In a game, it can appear as a creeping camera or a character moving on its own. A small non-zero reading alone is not proof of a fault: the controller reports positions in discrete steps.

Two shapes matter when you test:

  • A stable offset. Samples settle away from center, and a similar value and direction reappear from one test to the next.
  • An unstable or noisy signal. The value wanders even while the stick is at rest, so no single resting position explains it.

Offset and noise describe different parts of the signal. Neither figure identifies the physical cause by itself, so the test reports them separately.

What you need

  • A desktop computer. Windows, macOS, Linux or ChromeOS. Phones are not supported.
  • The standard PS5 DualSense. DualSense Edge and DualShock 4 are not supported.
  • A USB data cable. Some cables only carry power. If the controller never appears in the browser prompt, try another cable before anything else. On Linux the browser also needs permission to open the controller, usually a udev rule for its hidraw device.
  • Desktop Chrome or Edge. The browser talks to the controller through WebHID, which Chromium browsers provide and Safari and Firefox do not.

The calibration side of the tool rejects Bluetooth, so USB is required for the full workflow. If the controller is paired wirelessly, plug it in with the cable and connect again.

DualSense not detected in the browser?

An empty or cancelled browser prompt means no controller was selected. It does not identify the cause. If your DualSense was missing, try these checks:

  1. Use desktop Chrome or Edge and a standard DualSense. Phones, DualSense Edge and DualShock 4 are outside this tool's supported setup.
  2. Try a USB data cable and another USB port. A controller charging does not prove that the cable carries data.
  3. Close other tabs or apps using the controller, such as Steam or DS4Windows, then choose Connect DualSense again. If a calibration is already running, finish it or follow its Stop instructions first.
  4. If the browser says access was blocked, review the site's device permission before retrying. On Linux, the operating system must also allow the browser to open the controller's hidraw device; see Chrome's WebHID permission guidance.

After a successful connection, the automatic drift test only reads stick positions. It does not start calibration or write to memory. If input readings stop, check the USB connection before interpreting the result as a stick problem.

How to run the PS5 stick drift test

  1. Plug the DualSense into the computer with the USB data cable.
  2. Open Sense Calibrator in Chrome or Edge.
  3. Put the controller on a stable surface and release both sticks.
  4. Select Connect DualSense.
  5. Approve the browser prompt and pick the controller from the list.
  6. Keep the page visible and the sticks untouched while the automatic test runs. Read the result for each stick, then choose Run again to confirm it.

How the automatic test measures drift

The test collects about three seconds of input reports, discards initial settling samples and checks the signal spread in short windows. Windows with too much movement are excluded. If too little stable data remains, it retries; repeated instability produces a Moving result rather than a reliable resting offset. Missing or interrupted reports produce a connection warning.

From the samples that remain, it reports two numbers per stick:

  • Resting offset: the distance of the median stick position from center, as a percentage of the full range.
  • Noise: the distance within which 95% of the measured samples fall around that median.

The test cannot see your hand. A stick held still can produce a stable signal, so you must release it yourself. Movement or noise can have several causes and does not prove wear. The measurement logic is available in the GitHub repository.

How to read the result

Centered is below 1.2% offset. Within 1 step is the next band, up to 1.25%. Mild drift is below 3.5%, and Marked drift is below 15%; at 15% or more, the tool recommends Guided. These are the tool's measurement and routing bands, not a hardware diagnosis. Moving and Pinned take precedence over an offset label.

Reading What the numbers show Next step
Centered Offset below 1.2%. There is no center offset to correct. Check noise separately if a problem remains.
Stable offset An offset that repeats closely on a second test, with little variation. Calibration may help. Follow the tool's Quick or Guided recommendation.
Noisy signal The reported position varies around its median. Repeat on a stable surface. Persistent variation needs further investigation.
Pinned An axis reads at the edge with very little variation. Read the warning before starting Range. A stick that cannot leave the edge may never complete it.

Read both sticks' offset and noise together and repeat the test before changing anything. A noisy reading does not establish that a sensor is worn or dirty; the test does not inspect the mechanism.

Why the test is read-only

The automatic drift measurement reads input reports without sending calibration or memory-write commands. It does not create a calibration to save or undo.

Read-only by design. Choose calibration separately after reviewing the measurements. Writing its result to controller memory is another explicit action.

What a resting test cannot tell you

A quiet signal at rest does not prove that the stick module is healthy. A resting test cannot reproduce every in-game condition or assess the stick's full travel. If the problem persists with a centered reading, record when it happens and investigate further rather than assuming another center calibration will fix it.

What to do after the result

  • Centered and quiet: further center calibration is usually unnecessary. If a game still shows unwanted movement, the resting test alone has not explained it.
  • A repeatable offset: read how to calibrate a DualSense controller, then review both sticks' results before saving.
  • A noisy or pinned signal: follow the tool's warning and review the limits of calibration before starting a procedure.
