Sense Calibrator vs dualshock-tools

Both are free, open-source browser tools that calibrate PlayStation controller sticks through WebHID. dualshock-tools supports more controllers and more settings. Sense Calibrator only handles the standard DualSense, and it measures the sticks before and after calibration.

Where Sense Calibrator comes from

dualshock-tools is the established open-source project, hosted at dualshock-tools.github.io and released under the MIT License. Sense Calibrator's DualSense calibration commands are derived from it, and its license is included in the third-party notices.

Sense Calibrator is a separate project and is not affiliated with dualshock-tools or with Sony. It adds measurement and safety checks around those commands for one controller, rather than covering many.

When to use dualshock-tools

  • You have a DualShock 4 or a DualSense Edge. Sense Calibrator does not support them.
  • You want the interface in another language. dualshock-tools is translated into more than 20 languages.
  • You want finer manual control over the stick calibration, such as its finetune controls.
  • You already know the tool and its community. It has a longer track record, and on 12 October 2026 its GitHub repository had 765 stars and 265 forks, against 6 and 1 for Sense Calibrator.

When to use Sense Calibrator

  • You want numbers before you change anything. Connecting starts a read-only test that reports each stick's resting offset and noise. See the PS5 controller stick drift test guide.
  • You want guardrails around each procedure. Quick only starts when both sticks hold still near center, Guided checks that each stick was released after every corner, and Range tracks coverage before it enables Done.
  • You want to compare before saving. The result panel keeps both sticks' before and after offsets, and Write to memory stays a separate step. The DualSense calibration guide explains each procedure.

These checks reduce some risks; they do not make a calibration safe in every case. Read the tool's warnings before saving a result.

What neither tool can do

Calibration changes the values a controller uses to interpret its sensors. It does not clean or replace a worn stick. dualshock-tools is blunter on its own site: “This utility cannot fix stick drift.” It adds that calibrating without replacing the joysticks may help temporarily, “but it may also make the problem worse, with no way to undo it.” The PS5 stick drift fix guide helps you decide between calibration, a game deadzone and a repair.

Both tools need WebHID, so neither runs on a phone. Use a computer.

Sense Calibrator vs dualshock-tools FAQ

Is Sense Calibrator based on dualshock-tools?

Partly. Its DualSense calibration and memory commands are derived from dualshock-tools, which is released under the MIT License, and that license is included in the third-party notices. Sense Calibrator is a separate project, not affiliated with dualshock-tools or with Sony. Its drift test, safety checks and interface are its own.

Is dualshock-tools.github.io the same site as Sense Calibrator?

No. dualshock-tools.github.io is the dualshock-tools website. Sense Calibrator lives at martino-vigiani.github.io/sense-calibrator. Both run in the browser through WebHID, so both need a computer rather than a phone.

Which tool should I use for a DualSense Edge or a DualShock 4?

dualshock-tools. Sense Calibrator only supports the standard PS5 DualSense; DualSense Edge and DualShock 4 are not supported.

Can either tool fix stick drift caused by wear?

No. Calibration changes the values a controller uses to read its sticks. It can correct a stable resting offset, but it does not clean or repair a worn stick, and neither tool can make a worn stick hold its center.
