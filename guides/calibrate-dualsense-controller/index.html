How to calibrate a DualSense controller

Calibrating a DualSense controller means writing new center and range values to it. That can correct a stable offset, and it cannot repair worn, dirty or damaged hardware.

Start calibration Desktop Chrome or Edge · USB data cable · standard DualSense

When calibration can help

Every DualSense stores calibration values that describe where each stick rests at center and how far it travels toward the edge. The controller applies those values to the raw sensor signal before it reports a stick position. When the sensor still produces a clean, stable signal but the resting position no longer matches the stored center, the controller reports a constant offset and the game pulls in that direction.

That is the case calibration is built for. A diagnostic test separates a stable offset from a wandering signal: if the resting reading repeats with the same value and direction, writing a new center can correct it. A module that was replaced or repaired is a different case. Its travel may no longer match the stored range, and a range calibration gives the controller an accurate description of the new travel. You can start with the PS5 controller stick drift test to see which case you have.

A stable offset, or physical wear

A stable offset repeats with the same value and direction and does not wander while the stick is untouched. A worn or dirty module behaves differently: the reported position keeps moving, so the signal is noisy and unstable even at rest.

Calibration can shift a stable offset. It cannot clean a wiper, rebuild a worn track or fix damage. If the signal is noisy, calibrating around it only biases a failing sensor, because you are teaching the controller to treat a moving average as center. Check that the resting signal holds still before you calibrate. If it does not, the honest answer is service, not software.

Quick calibration versus Guided calibration

Sense Calibrator offers two center procedures and a separate range procedure. They differ in how much control you have and how the center is derived.

Quick calibration

Quick calibration is automatic. It samples the untouched sticks, writes a new center, then re-measures the residual and runs another pass if the offset is still above its target. It converges toward a good center instead of trusting a single attempt. Before it sends anything, both sticks must stay close to center for a short hold, within 15% of center for 300 ms, and that preflight check is repeated. If it fails, nothing is written: release the sticks and retry.

Guided calibration

Guided calibration is a four-corner procedure you complete by hand. The tool samples each corner in turn and derives the center from those points. It takes longer than Quick, and it is more accurate on marked drift. Once started it cannot be cancelled, so keep the controller connected and resting on a stable surface for the whole procedure.

Range calibration

Range calibration is separate and covers maximum travel. It asks you to rotate both sticks around the full edge while the tool samples the perimeter, which is useful after a module has been replaced or repaired.

Rest the controller on a stable surface

Every measurement is stability-gated. A hand on the stick, a hand holding the controller or a cable tug all read as movement. When the signal moves, the tool waits, widens its gate or refuses to send the calibration. Resting the controller flat and keeping your hands off it is what makes each reading trustworthy, for the drift test and for every calibration pass.

Temporary until you write it to memory

Everything the tool does first lives in the controller's RAM and takes effect immediately, so you can test it right away. It is discarded when the controller powers off. The calibration becomes permanent only when you choose Write to memory, which writes the values to the controller's non-volatile memory. A banner in the tool reminds you while a calibration is unsaved.

Safety net. Until you write to memory, powering the controller off restores the previous calibration. If a result looks wrong, turn the controller off instead of saving it.

Compare before and after

Run the drift test before calibrating and again afterward, and use the precision test for a second signal. If the numbers improve, save. If they do not, do not write anything: power-cycle the controller or recalibrate. The tool shows the before and after measurements, so the decision is based on readings rather than feel. The PS5 controller stick drift test explains how to read the resting offset and noise before you change anything.

What calibration cannot do

Calibration can correct stored center and range values. It cannot guarantee a permanent repair, it cannot fix worn, dirty or damaged hardware, and a controller whose signal keeps degrading will eventually need service. Sense Calibrator is an unofficial project and is not affiliated with Sony, so use it at your own risk and review the result before saving. The source code lives in the repository on GitHub, and the protocol behind it is described in the SubraLabs technical write-up.

Compatibility

Only the standard PS5 DualSense, USB product ID 054C:0CE6, is supported. The DualSense Edge and the DualShock 4 use different systems and are not supported. Calibration needs desktop Chrome or Edge and a USB data cable, and the tool rejects Bluetooth for calibration.

Before you start. Use a USB data cable rather than a charge-only cable, and open the tool on a desktop in Chrome or Edge. Safari and Firefox do not provide WebHID, so calibration cannot run there.

Start with your own controller

The drift test is read-only, so you can measure both sticks before deciding to change anything. To calibrate a DualSense controller, connect it over USB, run the test, and let the measurements make the decision.
