How to calibrate a DualSense controller

To calibrate a standard PS5 DualSense, connect it by USB in desktop Chrome or Edge, test the resting signal, then choose Quick or Guided in Sense Calibrator. Calibration may reduce a repeatable offset; it does not repair physical damage.

When calibration can help

A repeatable resting offset is a reason to evaluate center calibration. Start with the read-only PS5 controller stick drift test: release both sticks, compare their offset and noise, and repeat the measurement. Calibration can change the reported center, but improvement must be measured afterward.

If both sticks are already centered, another center pass may make the reading worse. If the signal is noisy or pinned at the edge, review the tool's warning first. The PS5 stick drift fix guide explains how calibration fits alongside game settings and further hardware checks.

Offset and noise are different measurements

Offset is the distance from center; noise describes variation around the resting position. A steady signal can still be off-center, and a centered median can still have noise. Neither stability nor noise proves whether a sensor is worn or dirty.

Calibration does not physically clean or repair a stick. It may change its reported offset, but a lower offset is not proof that the underlying problem is resolved. Repeat the test and check the behavior that brought you here.

Quick calibration versus Guided calibration

Sense Calibrator offers two center procedures and a separate Range procedure. Follow the recommendation shown for your measured result.

Quick calibration

Quick is automatic: leave both sticks released while the tool collects samples, applies a center calibration and measures the result. It may use more than one pass within its safety limits; it does not guarantee convergence or a better result.

Before starting a pass, both sticks must give fresh, stable readings within 15% of center for a 300 ms hold. If the initial check fails, calibration has not started. Release the sticks and retry, or follow the Guided recommendation if a released stick rests too far from center. A later interruption can leave a session open, so follow any instruction to turn the controller off.

Guided calibration

Guided asks you to move both sticks to four prescribed corners, one step at a time. Release both sticks after each movement, then press Continue. The calibration sample is taken after release, not at the corner.

The tool checks that both sticks reached the requested corner and then settled near a resting reference captured after the calibration session opened. A timed-out wait sends no sample. Use Guided when the tool recommends it, including when the resting offset is too large for Quick to start.

Keep the page open and the controller connected once you start. If the same corner cannot be reached twice, Stop and turn off controller lets you leave the incomplete session uncommitted. The controller must be turned off before another calibration. If readings stop or a rest check fails, no calibration sample is sent; follow the tool's recovery instructions. Disconnecting or reloading the page is not a substitute for a required power-off.

Range calibration

Range is separate from center calibration. Rotate both sticks around the full edge and change direction as instructed; the tool tracks coverage before enabling Done. Its intro sends no calibration command and explains the consequences before Start.

After Start, the session must be finished or the controller turned off. A pinned stick may never complete the required travel. An incomplete range cannot be written to memory, and a range procedure is not a guaranteed repair for a faulty or replaced module.

Release the sticks for resting measurements

Put the controller on a stable surface and release both sticks whenever the tool asks for a resting reading. Its checks can detect movement and reject unsuitable samples, but a stick held still can also look stable. A green movement meter does not prove that your hands are off.

Applied calibration and Write to memory

With controller memory confirmed locked, calibration is applied to working memory so you can test it before saving. Write to memory is a separate action that saves the active calibration to non-volatile memory. If the tool cannot verify the memory state, changes may not be temporary: review its warning before starting a procedure.

An unsaved calibration should revert to the last saved one after the controller powers off, but that behavior has not yet been confirmed on physical hardware. What happens after a USB unplug alone is also unverified. Neither is a proven rollback method, and the tool cannot restore a previous calibration pass.

Before saving. Do not write a result you want to undo. Writing to memory replaces the saved calibration; this tool does not offer a backup or restore of those saved values. If the tool requires a power-off to clear an open session, follow that instruction before continuing.

Compare both sticks before saving

The result panel keeps each stick's before and after offset on the page. Review both, then repeat the read-only drift test and check noise. A lower worst-stick figure alone can hide a regression on the other stick.

Write is disabled for unsafe or incomplete states, including a residual of 15% or more, a pinned axis, an open session requiring power-off and an incomplete range. Other concerning results can require a warning and second confirmation. These controls do not establish a physical repair: keep testing the behavior that matters to you before deciding to save.

What calibration cannot do

Calibration is not a guaranteed PS5 stick drift fix. It does not inspect or repair the mechanism, and it cannot guarantee a lasting result after cleaning, repair or a module replacement. If unwanted input persists, use the PS5 stick drift fix guide to review the next checks.

Sense Calibrator is an unofficial project and is not affiliated with Sony. Its source is available in the GitHub repository, and the protocol is described in the SubraLabs technical write-up.

Compatibility

Only the standard PS5 DualSense, USB vendor/product IDs 054C:0CE6, is supported. DualSense Edge and DualShock 4 are not supported. Calibration needs desktop Chrome or Edge and a USB data cable; the tool rejects Bluetooth for calibration.

Before you start. Use a USB data cable rather than a charge-only cable, and open the tool on a desktop in Chrome or Edge. Safari and Firefox do not provide WebHID, so calibration cannot run there.

Start with a read-only test

Connect your DualSense over USB, release both sticks and measure the resting signal before deciding to calibrate. The test itself sends no calibration or memory-write command.
