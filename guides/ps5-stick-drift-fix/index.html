First, test the PS5 controller for drift

A camera or character moving after you release the stick is a reason to investigate. The useful question is whether the controller reports the same offset each time, or whether its position wanders while untouched. A game can hide part of either signal with its deadzone, so compare the controller's readings as well as how it feels in play.

  1. Open Sense Calibrator in desktop Chrome or Edge. Connect a standard DualSense with a USB data cable and choose Connect DualSense.
  2. Put the controller on a stable surface and release both sticks. The automatic drift test reads their resting offset and noise without changing the controller.
  3. Run the test again without touching the sticks. Look at both sticks separately and check whether the reading repeats.

Only the standard PS5 DualSense is supported. DualSense Edge, DualShock 4 and Bluetooth calibration are outside this tool's supported setup. You can read this guide on a phone, but the test and calibration require a computer.

For the measurement details and result labels, read the PS5 controller stick drift test guide.

When calibration can fix stick drift

Calibration changes the center or range values the controller uses to interpret its sensors. It may help when an untouched stick reports a repeatable offset from center. That is a candidate for calibration, not proof that the mechanism is healthy.

  • A quiet, centered signal: there is no resting offset to correct. If a game still moves, check its controller settings and repeat the test under the conditions that trigger the problem.
  • A repeatable offset: try center calibration, then compare the new reading. Quick is automatic; Guided is available when Quick cannot start or the controller needs a different procedure.
  • A wandering or stuck signal: calibration may shift the center, but it cannot remove noise or repair a sensor. Review the test, avoid saving a bad result and consider service.

Quick requires both sticks to rest within its 15% startup radius. An offset outside that radius routes you to Guided rather than relaxing the check. This is a safety limit of the procedure, not a diagnosis of the hardware.

The DualSense calibration guide explains Quick, Guided, range calibration and the separate save step.

Reset, deadzone or repair: what each changes

A controller reset

Sony recommends a reset as a troubleshooting step for controller issues and provides a route to PlayStation Repairs for persistent analog-stick problems. Follow the official DualSense reset and troubleshooting instructions. A reset is a separate procedure from the center and range calibration in this tool; test again instead of assuming it corrected the offset.

A larger game deadzone

A deadzone tells a game to ignore a region near center. Increasing it can hide small unwanted inputs, while also ignoring some intentional small movements. It changes how that game responds, not the controller's sensor reading or stored calibration.

A hardware repair

A browser cannot clean a contact, rebuild a worn track or repair a damaged stick module. Noise, inconsistent returns or a stuck axis can warrant a hardware check, but a resting test alone cannot identify the faulty part. Check warranty and service options before opening the controller.

Check the result before saving

After calibration, Sense Calibrator shows each stick's before and after offset. Repeat the drift test and use the precision test to compare center and signal stability. A lower offset with persistent noise is an improvement in center, not a repair of the noisy signal.

The controller reports sticks on an 8-bit grid. A reading of 0.6% · at floor is the closest representable center in this tool. 1.2% · 1 step is a neighboring grid position. Chasing a displayed 0.0% is not a useful goal on that grid.

With controller memory confirmed locked, calibration takes effect in RAM and saving to non-volatile memory is a separate action. If memory state is unknown, changes may not be temporary: review the tool's warning first. Choose Write to memory only after reviewing the result. The tool disables saving for unsafe or incomplete outcomes and adds a confirmation for a result that got worse.

If the result is wrong, do not save it. Turning the controller off should return it to the last saved calibration, but this has not yet been confirmed on hardware. Unplugging USB alone is also unverified. Follow any power-off instruction shown by the tool before trying another calibration.

What if stick drift comes back?

First check whether the improved calibration was actually written to memory. A temporary result and a saved result are different. Then repeat the read-only test: a changing rest position or growing noise means the original correction may no longer fit the signal.

If calibration does not produce a usable result, avoid repeatedly saving new values in the hope that one will fix the mechanism. Use Sony's troubleshooting and service route, or have the controller assessed by a repair professional. There is no browser procedure that guarantees a permanent fix for every kind of PS5 stick drift.
